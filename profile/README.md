# Saverio Moretti — projects

Public projects of [Saverio Moretti](https://github.com/saveriomoretti), e-commerce developer (API integrations and
automation) in Arezzo, Italy.

- [superagent-method](https://github.com/saverio-moretti-dev/superagent-method): agent system for Claude Code, as a plugin
- [dont-waste-your-token](https://github.com/saverio-moretti-dev/dont-waste-your-token): Claude Code usage limits and a calibrated job queue
- [multimeter](https://github.com/saverio-moretti-dev/multimeter): audio analyzer in a single HTML file ([try it](https://saverio-moretti-dev.github.io/multimeter/))
- [reversibleimport](https://github.com/saverio-moretti-dev/reversibleimport): PrestaShop 8.1 CSV import with preview and undo
- [guardaroba](https://github.com/saverio-moretti-dev/guardaroba): offline-first web app for second-hand listings

Portfolio (in Italian): https://saverio-moretti-dev.github.io
